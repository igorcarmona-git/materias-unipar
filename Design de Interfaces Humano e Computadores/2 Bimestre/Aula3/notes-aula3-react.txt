async --> 	Cria uma função assincrona, uma função que só vai para a próxima linha
		se receber algum valor. 

await --> 	É usado pela função async para sinalizar onde voce quer esperar a resposta
		para executar a próxima linha.

Throw new Error('') --> Ele força uma exceção de erro e traz para o catch, usando try-catch
			(tratamento de erros).
