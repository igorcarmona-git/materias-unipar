Sobre o Roblox

Nesta página quero trazer conceitos relacionados ao jogo Roblox para melhor entendimento desta atividade.

Diferente de Minecraft, que é um sandbox (um jogo onde o jogador pode fazer e criar o que quiser), Roblox foi criado como uma ferramenta educacional para ensinar conceitos de Física para crianças.
